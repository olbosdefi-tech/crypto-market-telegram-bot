# Crypto Market Bot

A Telegram crypto market utility bot built with Python.

It provides live market data, personal watchlists, market movers, and automatic persistent price alerts.

## Features

- Live cryptocurrency prices
- 24-hour price change
- Market capitalization
- Top 5 cryptocurrencies by market cap
- Top 5 24h gainers
- Top 5 24h losers
- Crypto market snapshot
- Personal watchlists
- Persistent watchlists after restart
- Automatic price alerts
- Persistent alerts after restart
- Alert duplicate protection
- Automatic background price monitoring
- Custom branding through environment variables
